# 项目启动访谈问题库

用法：按项目上下文挑 1-3 个问题问，不要整张清单甩给用户。访谈最多两轮，第二轮后输出带 TBD 的草案。

## 第一轮：定方向

优先从这里选问题：

1. 这个项目大概几个人参与、预计做多久、出了问题是否容易回滚？我用这个判断 S/M/L。
2. 它要解决谁的什么具体问题？不做会有什么损失？
3. 如果 30/60/90 天后说“成了”，你希望看到哪 1-3 个可衡量结果？

适合给用户的选择题：

```text
这个项目更像哪一类？
A. S：1 人、两周内、可逆
B. M：2-6 人、1-2 个月、跨 1-2 个团队
C. L：多团队、季度级、高投入或对外发布
```

## 第二轮：定落地

优先从这里选问题：

1. 这次明确做什么、明确不做什么？
2. 谁是最终拍板人？谁负责推进？哪些人必须被咨询或知会？
3. 最大的 3 个风险或未验证假设是什么？
4. 依赖哪些系统、团队、预算、合规审批或外部资源？

## 用户要求跳过提问

当用户说“先别问”“按假设给草案”时，不追问，先输出：

```md
## 本草案采用的假设

- 项目量级：TBD，暂按 M 型处理。
- 目标用户：TBD，暂按主要业务使用方处理。
- 成功指标：TBD，先给建议指标，等待确认。
```

然后进入草案，并把所有不确定项标成 `TBD（负责人 / 截止日）`。

## 场景分流问题

### AI / 模型 / 数据项目

- eval 数据集来自哪里？谁确认标注质量？
- 哪些指标达标才算可上线？
- 哪些失败模式不可接受？
- 灰度放量路径是什么：内测、白名单、小流量、全量？
- 安全、隐私、合规谁拍板？

### 技术架构 / 系统改造

- 影响哪些系统、接口、数据表、上下游团队？
- 是否需要兼容旧版本？回滚路径是什么？
- 哪些性能、稳定性、安全指标必须守住？
- 是否有迁移窗口、冻结期或发布审批？

### 企业内部流程 / 管理项目

- 哪个部门是 owner，哪个部门只配合？
- 成功是降本、提效、合规、满意度，还是风险降低？
- 是否需要正式签字授权或预算审批？
- 推行阻力可能来自哪里？

### 内容 / 营销 / 广告项目

- 目标人群和主传播渠道是什么？
- 成功指标是曝光、线索、转化、成交还是品牌认知？
- 必须遵守哪些品牌、法务、平台规则？
- 交付物有哪些版本、尺寸、语言或渠道适配？
