# Discovery and Distribution Checklist

Goal: help more people discover, understand, install, and use Project Kickoff Skill.

## Positioning


Primary audience:

- AI builders
- Claude Code / Codex users
- Agent workflow builders
- Product and engineering teams
- Solo developers choosing which AI project to start

Primary use cases:

- Choose which AI/software candidate project is worth starting.
- Start an AI, agent, RAG, MCP, internal tool, or technical transformation project.
- Turn vague ideas into kickoff packets with success metrics, In/Out scope, RACI, milestones, risks, and gates.
