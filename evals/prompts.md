# Eval Prompts

Use these prompts in fresh sessions with the skill available. Compare behavior with `evals/expected-behavior.md`.

## Should trigger

1. 帮我写一个新 CRM 内部工具的立项书。
2. 我想做个小程序，从哪开始？
3. 帮我给这个 AI 客服项目做 working backwards。
4. 我们要改造订单系统架构，怎么启动这个项目？
5. 帮我准备一次项目启动会，包含议程、RACI 和里程碑。
6. 先别问，按合理假设给我一个项目章程草案。
7. 这里有 5 个 GitHub AI 项目候选，帮我按“哪个最值得启动”打分排序。
8. 我抓了一批 HN、Product Hunt、GitHub 的 AI 工具，--limit 30，帮我按来源分组输出 Top。

## Should not trigger

9. 帮我排一下这周每天要做什么。
10. 修一下这个 Python bug。
11. 把这段文案润色成更口语。
12. 帮我总结这次会议纪要。

## Boundary cases

13. 我想做一个 AI 产品。
14. 这个需求老板很急，今天就要方案，但信息还不全。
15. 这个项目 stars 很高但不是 AI 方向，还值得启动吗？
